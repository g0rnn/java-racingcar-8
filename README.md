# java-racingcar-precourse

## 모델링

### 자동차

```
우선순위: p1

[프로퍼티]
- 자동차는 이름, 위치를 가진다.
  + 이름은 5자 이하
  + 위치는 0 이상
[행위]
- 전진 조건(4 이상)을 만족하면 자동차는 움직인다.
- 한 라운드가 끝나면 자동차는 이름과 현재 위치를 표현한다.
```

### 게임 진행자

```
우선순위: p1

[프로퍼티]
- 게임을 가진다.
[행위]
- 경기 우승자를 결정한다.
- 게임을 실행한다.
```

### 게임

```
우선순위: p2

[프로퍼티]
- 총 랩(lab)수를 가진다.
- 게임에 참여하는 자동차를 가진다.
- 랩 수와 참여하는 자동차는 다음의 유효성을 따른다.
  + 총 랩 수는 최대 100_000이다.
  + 참여하는 자동차는 최소 1대, 최대 100_000대 이다.
```

## 요구사항

#### 기능

- [v] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- [v] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- [v] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.


- [v] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [v] 자동차는 5자 이하의 이름을 가진다.
- [v] 자동차 이름은 중복될 수 없다.
- [v] 전진하는 조건은 값이 4 이상일 경우이다.
- [v] 전진하는 조건은 0에서 9 사이에서 무작위 값을 통해 구한다.
- [v] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.


- [v] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

#### 입출력

- [v] 공백("", " ") 입력 시 예외를 던진다.
- [v] 경주할 자동차 이름은 다음 조건을 만족해야 한다.
    - [v] 이름은 쉼표(,) 기준으로 구분한다.
    - [v] 이름은 영문, 한글로 시작할 수 있으며 숫자를 포함할 수 있다. (ex. "gyun1" -> O, "1gyun" -> X)
- [v] 시도할 횟수는 1보다 큰 숫자를 입력해야 한다.
- [v] 차수별 실행결과는 이름과 현재 위치를 출력(이름과 현재위치는 " : "로 구분)한다.
- [v] 단독 우승자 안내 문구는 `최종 우승자 : ${이름}`이다.
- [v] 자동차 이름, 시도할 횟수를 입력받기전 질문을 출력한다.
- [v] "실행 결과" 문구 뒤에 실행결과를 순서대로 출력한다.
- [v] 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
